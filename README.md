# 나의 기록장 (Personal Tracker PWA)

일정 관리 + 투자 판단 기록 + 일기를 한 곳에서 관리하는 개인용 PWA입니다.
서버/계정/백엔드 없이 순수 정적 파일로 동작하며, 모든 데이터는 브라우저의 IndexedDB에 저장됩니다.

## 폴더 구조

```
personal-tracker-pwa/
├── index.html          # 홈 (3개 메뉴)
├── schedule.html/js     # 일정 (월 캘린더)
├── investment.html/js   # 투자 기록 (비밀번호 필요)
├── diary.html/js        # 일기 (비밀번호 필요)
├── settings.html/js     # 비밀번호 설정/변경, 데이터 백업
├── manifest.json         # PWA manifest
├── service-worker.js     # 오프라인 캐싱
├── css/style.css
├── js/{utils,db,auth,pwa}.js
└── icons/                # 홈 화면 아이콘 (PNG)
```

## 로컬에서 확인하기

서비스 워커는 `file://`에서 등록되지 않으므로, 로컬 정적 서버로 열어야 합니다.

```bash
cd personal-tracker-pwa
python -m http.server 8000
```

브라우저에서 `http://localhost:8000` 접속.

## GitHub Pages에 배포하기

1. 이 폴더(`personal-tracker-pwa`)를 GitHub 저장소 루트로 두고 커밋/푸시합니다.
   ```bash
   cd personal-tracker-pwa
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/<사용자명>/<저장소명>.git
   git push -u origin main
   ```
2. GitHub 저장소 → Settings → Pages → Source에서 `main` 브랜치 / `/ (root)` 선택 후 저장합니다.
3. 잠시 후 `https://<사용자명>.github.io/<저장소명>/` 로 접속되면 배포 완료입니다.

`manifest.json`의 `start_url`/`scope`가 상대경로(`./`)로 되어 있어 저장소 이름이 무엇이든(서브경로 배포) 그대로 동작합니다.

## 아이폰 Safari에 설치하기

1. Safari로 배포된 주소를 엽니다.
2. 공유 버튼(⬆️) → "홈 화면에 추가" 선택.
3. 홈 화면 아이콘으로 실행하면 주소창 없는 앱처럼(standalone) 동작합니다.

## 대한민국 공휴일 표시

- `js/holidays-kr.js`에 2024~2027년 공휴일(대체공휴일 포함)을 정적 데이터로 내장했습니다. 서버·외부 API 호출이 전혀 없으므로 오프라인에서도 그대로 동작합니다.
- 설날·추석·부처님오신날처럼 음력 기준이라 매년 날짜가 달라지는 공휴일은 공식 발표 자료를 직접 찾아 확인한 값이며, 나머지 고정일(신정·삼일절 등)의 대체공휴일 여부는 실제 요일 계산 결과를 반영했습니다. 범위를 벗어난 연도는 공휴일 표시가 되지 않으니, 필요하면 `HOLIDAYS_KR` 객체에 연도를 추가해서 확장하면 됩니다.
- 캘린더 셀에 공휴일명이 빨간 글씨로 작게 표시되고, 날짜를 선택하면 하단 목록 제목 옆에도 "🎌 공휴일명"이 붙습니다.

## 일정 화면 게이미피케이션

- 날짜를 선택하면 기존 일정 목록 아래에 "오늘의 할 일 체크리스트" 섹션이 나타납니다. 자유 텍스트로 항목을 추가하고, 체크박스로 완료/미완료를 전환하거나 삭제할 수 있습니다.
- 항목 추가 시 반복 주기(반복없음/매일/매주/매달)를 선택할 수 있고, 일정과 동일한 규칙으로 이후 날짜를 열어볼 때마다 그날의 새 항목이 자동 복제됩니다(과거 기록은 유지, 날짜별로 개별 체크 상태를 가짐). 반복 항목을 삭제하면 일정과 마찬가지로 모든 날짜의 기록이 함께 삭제됩니다(확인 후 진행).
- 체크 완료 시 10점 획득, 체크 해제 시 10점 차감됩니다. 캘린더 최상단 대시보드 카드에서 오늘 완료/전체, 오늘 획득 점수, 누적 총점, 100% 완료한 날짜 수, 연속 달성일(streak)을 확인할 수 있습니다.
- 체크리스트 데이터는 `checklistItems`라는 별도 IndexedDB 저장소에 저장되며, 설정 화면의 백업 내보내기/가져오기에도 포함됩니다.

## 비밀번호 안내

- "투자 기록"과 "일기"는 같은 비밀번호를 공유합니다.
- 최초 진입 시 비밀번호를 설정하며, 설정 화면에서 언제든 변경/초기화할 수 있습니다.
- 클라이언트 측 해시(SHA-256 + salt) 비교 방식으로, **완전한 보안이 아닌 간단한 잠금**입니다. 데이터 자체를 암호화하지는 않습니다.

## 데이터 백업

모든 데이터는 이 기기의 브라우저 안에만 저장됩니다(서버 없음). 기기를 바꾸거나 브라우저 데이터를 지우면 기록이 사라질 수 있으므로,
설정 화면의 "백업 파일 내보내기"로 주기적으로 JSON 백업을 남기는 것을 권장합니다. "백업 파일 가져오기"로 복원할 수 있습니다.
